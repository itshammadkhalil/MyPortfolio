# Hammad Khalil | Personal Portfolio

A sleek, high-performance personal portfolio built to showcase my expertise as an AI & Web Architect. This project highlights my professional journey, skills, certifications, and recent projects, ensuring a smooth and responsive experience across all devices.

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript
- **Icons**: Lucide React & React Icons

## ✨ Features

- **Hero Section**: Engaging introduction featuring dynamic typewriter effects.
- **About Me**: Brief overview of my background, stats, and professional traits.
- **Skills**: Detailed breakdown of technical proficiencies, tools, and soft skills.
- **Certifications Wall**: Responsive grid showcasing achievements with category filtering and pagination.
- **Projects Showcase**: Case studies of my latest work including the NovaStack Outreach Dashboard and Feasto Food Ordering App.
- **Client Feedback**: Testimonials from satisfied clients highlighting successful collaborations.
- **Contact Form**: Functional, sleek contact form integrated with Formspree for direct communication.

## 🛠️ Local Development

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/itshammadkhalil/MyPortfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd MyPortfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
